# Mushroom Prediction API

A simple machine learning project that predicts whether a mushroom is **edible**
or **poisonous** from 22 categorical features. It uses scikit-learn for training
and FastAPI for predictions.

> Educational use only. Do not use this model to decide whether a wild mushroom
> is safe to eat.

## Quick start

Use Python 3.11 or newer. Run these commands from the project folder.

### 1. Set up the environment

```bash
python -m venv .venv
```

Activate it on macOS / Linux:

```bash
source .venv/bin/activate
```

Or on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### 2. Train the model

Make sure the dataset is at `data/mushroom/mushrooms.csv`, then run:

```bash
python train_mushroom.py
```

Training compares logistic regression, decision tree, and random forest using
5-fold cross-validation. It selects a model, chooses a probability threshold
using training data, and evaluates on a separate 20% test set.

The model, one-hot encoder, feature names, threshold, and metadata are saved
together in `models/mushroom.joblib`. Unknown stalk-root values (`?`) are kept
as their own category.

To choose a model explicitly:

```bash
python train_mushroom.py --algorithm "random forest"
```

### 3. Start the API

```bash
python -m uvicorn app.main:app --reload
```

Open **http://127.0.0.1:8000/docs** to try the API. Under
`POST /mushroom/predict`, click **Try it out**, use the example request, and
click **Execute**.

Train the model before starting the API. After retraining, restart the API to
load the new model.

## API endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/health` | Check whether the model is loaded |
| GET | `/models` | View the model, features, metrics, and threshold |
| POST | `/mushroom/predict` | Predict one mushroom |
| POST | `/mushroom/predict/batch` | Predict 1–1,000 mushrooms |

Requests use all 22 feature names and their one-letter dataset codes, such as
`"cap-shape": "x"` and `"odor": "p"`. Use `"?"` for an unknown `stalk-root`.
Missing fields, extra fields, and invalid codes return **422**.

Example response:

```json
{
  "label": "poisonous",
  "poisonous_probability": 0.98,
  "will_be_poisonous": true,
  "threshold": 0.5
}
```

The label is `poisonous` when the probability is greater than or equal to the
saved threshold. The threshold is selected during training; check `/models`
for its actual value.

If the model file is missing, `/health` reports `degraded` and prediction
requests return **503**. Train the model and restart the API.

You can also send the example requests in `requests.http` using a compatible
HTTP client extension.

## Project structure

```text
app/
  main.py                 API endpoints and startup
  schemas.py              Request and response validation
  ml.py                   Model loading and prediction
data/mushroom/
  mushrooms.csv           Training dataset
models/
  mushroom.joblib         Generated by training (ignored by Git)
notebooks/
  mushroom_model.ipynb    Model training notebook
train_mushroom.py         Training script
requests.http             Example API requests
tests/                    Automated tests
requirements.txt          Dependencies
```

## Dataset

The [UCI Mushroom dataset on Kaggle](https://www.kaggle.com/datasets/uciml/mushroom-classification)
contains 8,124 samples and 22 categorical features. The target column is
`class`: `e` means edible and `p` means poisonous.

python -m pytest -q
